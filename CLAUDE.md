# CLAUDE.md

## Data integrity

All data populated into this project's tables (planets, people, factions, spacecraft, quotes, etc.) must be sourced from real, verifiable material — the Spaceballs (1987) film itself, its script, or reference sites like the Spaceballs Fandom wiki. Never fabricate or guess field values (e.g. invented climate/gravity/population stats) to fill out a schema. If a value can't be sourced, leave the column null or omit it rather than making one up.
